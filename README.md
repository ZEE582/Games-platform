# منصة الألعاب Games Platform

منصة ألعاب ويب شاملة تجمع بين مجموعة متنوعة من الألعاب المسلية في مكان واحد.

## 🎮 الألعاب المتاحة

### ألعاب المتصفح

- **لعبة الطيور** (Flappy Bird) - لعبة طيران بسيطة وممتعة
- **XO** - لعبة أكس أو الشهيرة
- **الحظ** - لعبة حظ متنوعة
- **الثعبان** (Snake) - لعبة الثعبان الكلاسيكية
- **كرة القدم** - أسئلة كرة قدم ممتعة

### ألعاب أخرى

- **أذكار** - مجموعة من الأذكار الإسلامية
- **ركبي** (RBS) - لعبةركبي

## 🚀 التقنيات المستخدمة

- **React** - إطار عمل JavaScript
- **TypeScript** - لغة برمجة آمنة
- **Supabase** - قاعدة بيانات وأمان
- **Material UI** - تصميم واجهة المستخدم
- **React Router** - إدارة المسارات

## 💻 متطلبات التشغيل

- Node.js (الإصدار 18 أو أحدث)
- npm أو yarn

## 📦 التثبيت

```bash
# استنساخ المشروع
git clone https://github.com/ZEE582/Games-platform.git

# الانتقال إلى مجلد المشروع
cd Games-platform

# تثبيت المتطلبات
npm install

# تشغيل المشروع
npm start
```
